# 🎯 About the Repository

This repository contains the practical implementation of concepts covered in the **SQLite laboratory**.

The experiments follow the progression specified in the course plan, starting with SQLite installation, database creation and SQL syntax, and gradually progressing towards database design, CRUD operations, data retrieval, aggregate functions, joins, date and time functions, keys and constraints, triggers, integrated SQL queries, and a final database project.

The laboratory focuses on developing practical skills in:

- SQLite database management
- SQL syntax
- Database creation
- Table creation
- Data types
- CRUD operations
- Data retrieval
- Conditional queries
- Sorting
- Aggregate functions
- Grouping
- Joins
- Date and time functions
- Primary keys
- Foreign keys
- Constraints
- Triggers
- Database design
- Integrated SQL queries
- Database application development
